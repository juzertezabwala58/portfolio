# 💻 Python Projects, Automation & Systems

This directory contains real-world Python applications, relational database systems, web scrapers, data structures, and visualization notebooks.

---

## 📂 Projects & Modules

### 1. [Enterprise Banking Management System](./banking_management_system/)
- **Architecture**: 3-Tier OOP Console application backed by SQLite (`bank_system.db`).
- **Features**: 4 role portals (Super Admin, Branch Admin, Bank Employee, Customer), transactional ledger, atomic fund transfers, account opening, and loan management.

### 2. [Automation & Web Scraping Utilities](./automation_and_utilities/)
- **Image Downloader**: Multi-threaded, batch image scraper with query filtering and download limits.
- **YouTube Downloader**: Video & playlist downloader supporting 1080p, 720p, and MP3 audio extraction.
- **QR Code Generator**: Dynamic QR code generator with custom color schemes and scaling.

### 3. [Data Structures: Stacks & Queues](./data_structures_stacks_and_queues/)
- **Implementations**: OOP linear Stack, FIFO Queue, and Circular Queue with overflow/underflow handling.

### 4. [Python Data Visualization](./data_visualization/)
- **Visualizations**: Statistical outlier detection using the IQR method, boxplots, and Matplotlib plotting.
