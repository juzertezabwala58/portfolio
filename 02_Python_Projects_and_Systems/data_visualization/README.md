# 📈 Python Data Visualizations & Statistical Plotting

## 📌 Project Overview
A practical Python visualization project demonstrating data plotting, continuous function modeling, and statistical outlier identification using **Matplotlib** and **NumPy**.

---

## 🔬 Topics & Demonstrations
- **IQR Statistical Outlier Detection**: Interquartile range ($Q_3 - Q_1$) boundary filtering for data cleaning.
- **Boxplot Profiling**: Identifying distributions, whiskers, and medians.
- **Trigonometric & Mathematical Curves**: Continuous wave visualization using `np.linspace` and coordinate plotting.

---

## 📁 Files Included
- `statistics_and_visualizations.ipynb`: Interactive Jupyter Notebook containing all plotting routines.

---

## ⚡ How to Run
```bash
jupyter notebook statistics_and_visualizations.ipynb
```
