# 🏅 Sports Analytics: Player Performance & Metrics Dashboard

## 📌 Project Overview
A specialized sports analytics Power BI dashboard focusing on multidimensional player performance metrics, career milestones, head-to-head records, and form analytics.

---

## 📊 Dashboard Focus & Features
- **Individual Player Scorecards**: In-depth breakdowns of batting and bowling contributions.
- **Match-Impact Metrics**: Performance indexing under pressure, runs scored in winning vs losing causes, and consistency ratings.
- **Interactive Slicers & Filters**: Dynamic filtering by team, opposition, tournament edition, and venue conditions.

---

## 📁 Files Included
- `player_stats.pbix`: Interactive Microsoft Power BI Dashboard report.

---

## ⚡ How to Open
1. Launch **Microsoft Power BI Desktop**.
2. Open `player_stats.pbix`.
